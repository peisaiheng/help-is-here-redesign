# Help Is Here: website redesign (reference prototype)

A static redesign of hih.com.sg, built on the Help Is Here design system, published here so the team can review it before a hosting and tech-stack decision is made.

- **Not the live site.** This build is marked `noindex` and is not meant for search engines or customers.
- **Photography is AI-generated placeholder imagery.** It must be replaced with real HIH helpers and families before launch.
- **Forms are not connected** to any backend; they show a sample confirmation only.
- Chinese (简体中文) pages are draft translations pending native-speaker review.

Source lives in [`site/`](site/). See [`site/README.md`](site/README.md) for how it is built.
